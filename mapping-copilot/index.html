Mapping Copilot

Most of my integration work started with the same chore: put a record from one system next to a record from another and decide which field feeds which. Here Claude drafts that mapping with a confidence score for every line, a person approves or rejects each one, and the page runs the approved mapping on the sample record.

    How it's built
    
      
    
        
    This pageStatic HTML on GitHub Pages. Sends only the two records.
    
        
    →
    
        
    Cloudflare WorkerHolds the API key. Checks the origin, rate-limits and size-checks every request.
    
        
    →
    
        
    Claude APIClaude Opus 5.5 with structured outputs: the answer must match a JSON schema.
    
        
    →
    
        
    You, then the engineNothing runs until a person approves it. A small engine in the page runs the approved lines.
    
      
    
      
    
        
    Claude drafts, a person decides
    Lines below 80% confidence start unapproved, and only approved lines run. It's the same rule I gave my Boomi agent: when the change matters, a person signs off.
    
        
    The model returns a plan, not code
    Claude picks each line's transform from a fixed list of 13, and the page's own engine runs them. Nothing the model writes is ever executed, so a malicious record can't run code in your browser. Paths like __proto__ are refused.
    
        
    A schema instead of string parsing
    The request uses structured outputs, so the model's response has to match a JSON schema. The page checks it again before showing anything.
    
        
    Records stay data
    The system prompt lives on the server, and visitors can only send records. If a record contains text that looks like an instruction, Claude maps it as an ordinary value and flags it.
    
        
    It asks when it doesn't know
    Internal IDs and subsidiaries can't be inferred from a sample record. Instead of inventing one, Claude lists the question for a person, and the answer becomes part of the mapping.
    
        
    Built not to run up a bill
    The key never reaches the browser. Only this site's origin can call the Worker, each visitor gets 5 requests a minute, records are capped at 8 KB, and the account has a monthly spend limit.
